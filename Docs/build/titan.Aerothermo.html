Recalculates flow direction on a per-facet basis, returns array of flow directions and array of local Machs

Optionally can enable facets rotating into the flow experiencing faster relative velocity, this models a dissipative effect to rotation to prevent unbounded spinning.

Assembly:

Assembly to calculate per facet flows for

Flow_direction:

The unit vector of the assembly’s velocity

Do_pfm:

Whether to perform local rotational damping
