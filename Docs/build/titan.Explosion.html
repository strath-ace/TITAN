titan.Explosion.explosion_fragments module#

titan.Explosion.explosion_fragments.build_new_assemblies(fragment_list, titan, options, i_parent, explosion_parameters)#

Takes a collection of fragments, builds each a new “assembly” and appends it to titan.assembly

Parameters:

  • fragment_list – Object of class AssemblyList, generated by fracture_object() :param titan: Object of class AssemblyList :param options: Object of class Options

  • i_parent – Index of the parent assembly of pre-exploded object

  • explosion_parameters – Dict of kinetic parameters, generated by fracture_object()

titan.Explosion.explosion_fragments.calculate_fragment_dv(fragment_assem, frag_id, explosion_parameters, options)#

Computes change in velocity for each fragment in an explosion

Parameters:

  • fragment_assem – Object of Class Assembly

  • frag_id – Index of fragment in explosion_parameters dict

  • explosion_parameters – Dict of kinetic parameters, generated by fracture_object()

  • options – Object of Class Options

titan.Explosion.explosion_fragments.evolve_4_explosion_velocity(base_v, area_mass_ratio)#

NASA EVOLVE 4.0 Explosion Velocity Distribution Function

Parameters:

  • base_v – Base velocity

  • area_mass_ratio – Area to mass ratio of the fragment

See https://doi.org/10.1016/S0273-1177(01)00423-9

titan.Explosion.explosion_fragments.fracture_object(explobject, parent, options, dt=None, base_rng=None)#

Takes a demising component and returns a collection of fragments to be added to the simulation

Parameters:

  • explobject – Object of class Component to fracture and disperse

  • parent_state – Object’s parent assembly

  • options – Object of class Options

  • dt – Duration of explosion in seconds

  • base_rng – Object of class numpy.random.RandomState defining global rng

titan.Explosion.explosion_fragments.sample_fragment_velocities(explosion_parameters, n_fragments, options, dt=None)#

Select delta velocities assigned to fragments based upon a velocity method

Parameters:

  • explosion_parameters – Dict of kinetic parameters, generated by fracture_object()

  • n_fragments – Number of fragments

  • options – Object of Class Options

  • dt – Duration of explosion in seconds
