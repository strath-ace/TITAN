titan.Geometry.assembly.create_assembly_flag(list_bodies, Flags)#

Generates the assembly connectivity matrix

Creates a flag m*n where m is the number of assemblies and n is the sum of all components used in the simulation. For every component belonging to a Body, the flag is True on that position. The assemblies are created according to the generated matrix

Parameters#

list_bodies: array of components

array containing the used-defined components

Flags: np.array

numpy array containing the linkage information of each component

Returns#

assembly_flag: np.array

numpy array containing information on how to generate the assemblies with respect to the components introduced in the simulation
