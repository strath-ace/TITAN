Running TITAN#

titan.run_TITAN.loop(options=[], titan=[])#

Simulation loop for time propagation

The function calls the different modules to perform dynamics propagation, thermal ablation, fragmentation assessment and structural dynamics for each time iteration. The loop finishes when the iteration number is higher than the one the user specified.

Parameters:

  • options (Options,) – Base TITAN options

  • titan (Assembly_list) – Base TITAN object

titan.run_TITAN.main(filename='', postprocess='', filter_name=None, emissions='')#

TITAN main function

Parameters:

  • filename (str) – Name of the configuration file, defaults to “”

  • postprocess – Postprocess method. If specified, TITAN will only perform the postprocess of the already obtained solution in the specified output folder.

The config file still needs to be specified.
